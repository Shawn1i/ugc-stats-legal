Privacy Policy

UGC Stats · last updated October 1, 2026

UGC Stats is a private tool that reads statistics for accounts owned by its operator. It collects only what TikTok's API returns for the approved permissions: basic profile info (username, display name), follower/like/video counts, and per-video statistics (views, likes, comments, shares) for the owner's own videos.

Storage: access tokens and fetched statistics are stored only on the owner's personal computer. Nothing is sold, shared with third parties, or used for advertising.

Retention and deletion: data is kept only as long as needed for personal reporting. Revoking the app in TikTok (Settings → Security → Apps and websites) stops all access, and stored tokens can be deleted at any time.

This policy may change; the date above shows the latest version.
